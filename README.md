# EnglishGram 

**EnglishGram** is a web-based platform designed to help users learn and improve their English language skills. It provides learning materials, vocabulary, grammar explanations, and practical exercises in one place.

🌐 **Live Demo:** [https://andriilyvyn.github.io/language-page/](https://andriilyvyn.github.io/language-page/)

## 📖 Features

The website offers several sections to support English language learning:

### ⏳ English Tenses
- Overview of the 12 English tenses.
- Grammar explanations.
- Examples to help understand different tenses.
- Learning materials covering present, past, and future forms.

### 📚 Vocabulary
- English vocabulary organized by proficiency levels.
- Words ranging from A1 to C1.
- A dictionary to help users discover and learn new words.

### 💪 Exercises
- Reading practice.
- Writing practice.
- Activities designed to improve language comprehension and communication skills.

### 🗣️ Phrasebook
- Useful everyday English expressions.
- Practical phrases for different situations.
- Vocabulary for shopping, travelling, dining out, and everyday communication.

### 📖 Part of Speech
- Learning English parts of speech.
- Understanding the role of words in sentences.

### 💬 Simple Talk
- Simple English conversations.
- Practical language examples for everyday communication.

## 🎯 Project Goals

The main goal of EnglishGram is to make learning English more accessible, engaging, and enjoyable.

The platform aims to:
- Help learners improve their English grammar.
- Expand vocabulary and language knowledge.
- Develop reading and writing skills.
- Improve everyday communication.
- Provide accessible learning materials for different proficiency levels.

## 🚀 Getting Started

You can access the website directly through GitHub Pages:

[Open EnglishGram](https://andriilyvyn.github.io/language-page/)

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/AndriiLyvyn/language-page.git
   ```

2. Navigate to the project directory:

   ```bash
   cd language-page
   ```

3. Open `index.html` in your web browser.
